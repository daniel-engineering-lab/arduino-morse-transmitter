Arduino Morse Code Transmitter

English

A work-in-progress Arduino project focused on transmitting and receiving Morse code.

Current status: Developing the transmitter prototype using button input, timing logic, LED feedback, and serial output.

Română

Un proiect Arduino în curs de dezvoltare, axat pe transmiterea și recepționarea codului Morse.

Stadiu actual: Dezvoltarea prototipului emițătorului folosind intrarea de la un buton, logica de temporizare, feedback vizual prin LED-uri și ieșire serială.
